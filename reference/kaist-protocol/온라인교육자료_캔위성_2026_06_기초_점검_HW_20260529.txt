캔위성 기본 키트 – 기초 점검 ( 전원 넣기 전 )
   목표 : 전원 넣기 전 보드 전원 안정성 점검
   준비 : 캔위성 기본 키트                                        GND ,3.3V,GND,5V

   수행 : 전원 OFF 상태 : 보드 제작 점검 및 전원 점검개별  납땜 눈으로 확인 (육안검사)
                                     . 보드와 핀사이를 납으로 연결하고 있어야 함
                                     . 핀 이외에 다른 곳에 묻지 않아야 함
   확인1 : 보드 제작 점검 ( 육안검사 )
      납땜 점검
       • 개별 납땜 확인 (보드와 핀사이)
       • 납땜이 다른 곳에 묻지 않아야 함     GND → CASE              GND 와 입력 (X)           GND 와 다이오드 (X)
      케이블 점검                       ( 소리 )

       • 커넥터 별로 각각의 케이블 손상 여부 확인
   확인2 : 보드 전원 상태 점검 ( 멀티미터 사용 )
      연결성 (Short) 점검 (GND 기준)                  GND → 5V (X)   GND → GND (O)     GND → 3.3V (X)
       • 케이스 및 GND 점검 (부저 소리)
       • 3.3V / 5V / 입력과 연결 점검 (소리 없음)
       • 다른 층 GND/3.3V/5V 점검                   GND → 5V (X)   GND → GND (O)     GND → 3.3V (X)

        ( 13핀의 경우 5V , GND, 3.3V, GND 순서 임 )
   확인3 : 배터리 전압 점검 ( 멀티미터 사용 )
     최대 4.2V x2 = 8.4V, 일반 3.7V x 2 = 7.4V
    주의) 전원 OFF 상태에서 점검 수행, 3.3V 레귤레이터 접촉 주의                                        배터리 전압 측정
    주의) 보드 점검이 잘못된 상태에서 전원을 넣으면 보드가 손상될 수 있습니다.

캔위성 기본 키트 – 기초 점검 ( 전원 )
   목표 : 캔위성 기본 키트 HW 전원 점검
   준비 : 캔위성 기본 키트
   수행 : 전원 스위치 ON
   확인 : 캔위성 LED 확인
      LED : 5V
      LED : 3.3V
      주) 모든 층에서 하나만 켜질 경우
                                        전원 스위치 OFF 상태         전원 스위치 ON 상태
        • 대부분 배터리가 약할 경우이며
        • 충전이 필요함
        • 충전시 8.4V 아답터 사용
        [배터리가 장착된 경우
         - 직접적으로 12V 아답터 사용 금지]

      LED : 상태표시
        • 정상 동작시 LED ON/OFF 를 반복함
                                        전원 LED ON 상태          프로세서 동작 상태 표시 (깜박임)
                                        ( 보드별 5V, 3.3V 표시 )   . Bootloader 동작시 1개만 깜박임
   마무리: 전원 스위치 OFF                                            . FSW 운용 시 상태를 표시함

캔위성 기본 키트 – 기초 점검 : 유선 ( USB ) 통신
   목적 : USB 를 통한 기초적인 유선 점검
   준비 : 캔위성 2층 보드, USB 케이블
   USB 케이블을 통한 통신 점검
      캔위성 2층 보드
      SWITCH 를 USB로 설정                                     BT 수신 명령을 캔위성 에서 수신 가능(기본)
       • 일반적인 경우 BT로 설정
       • 캔위성에서 전송한 것은 BT,USB,ISP 동시 전달함. (SW무관)
   연결 방법 ( 캔위성, uUSB 케이블, PC 연결 )
      캔위성 SWITCH 를 USB방향으로 변경
      캔위성 uUSB 포트에 케이블 연결
                                                   USB 전송 명령을 캔위성에서 수신 가능
      PC 와 USB 케이블 연결
      PC 에서 USB (to Serial) 포트가 연결된 통신 포트를 이용하여
      Cansat_Gs.exe 프로그램으로 연결 ( ex, COM3, 115200 )
      캔위성에서 전송한 통신 확인
      2026 보드에서 USB 연결시 2층 다이오드를 거쳐
      USB를 통해 캔위성으로 전원이 공급됨
      ( 전원 공급이 없는 상태에서도 간단한 통신 점검은 가능 )            Cansat_GS 의 PORT DATA DIALOG 창
      ( 하지만, 전원 공급이 부족하므로 배터리나 외부 전원 사용 필요 )( USB 로 보내지는 데이터 확인 가능 )
