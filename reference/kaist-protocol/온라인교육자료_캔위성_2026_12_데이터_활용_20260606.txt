캔위성 기본 키트 – 지상국 데이터 개요
  상태 정보 창 ( UI )
      DTLM 데이터 표시, ( GPS 데이터 표시 )
      IMU 데이터 표시
      GPS 데이터 표시
      ATLM 데이터 표시
      Image 수신 및 저장 표시
      일반 상태 및 송신 정보 표시(메시지표시)
  상태 정보 저장 파일 ( LOG : CSV)
      상태 창 정보를 시간 단위로 저장
      CansatLog/CansatLog_YYMMDD/CansatLog_YYMMDD_HH.csv 파일로 저장
       • YY : 년도에 해당 ( 16 ➔ 2016 년 )
       • MM : 월에 해당 ( 05 ➔ 5월      )
       • DD : 일에 해당 ( 27 ➔ 27일     )
       • HH : 시에 해당 ( 23 ➔ 23시     )
      저장된 데이터는 YYMMDD_HHMMSS,수신데이터 형태로 저장
  사진 저장 파일 ( PICTURE : JPG)
      수신 사진 저장
      CameraImage/Picture_YYMMDD/Picture_YYMMDD_HHmmSS[_N].jpg
         • mm : 분에 해당
         • SS : 초에 해당
         • [_N] : 같은 초에 여러 사진이 있을 경우

캔위성 기본 키트 – 지상국 데이터 구분
  상태 정보의 각 데이터는 콤마(,) 로 구분하고 있다.
  DTLM (디지털 원격검침) 데이터
      캔위성의 디지털 상태 정보 이다.
      DTLM 으로 시작하며,
      32개의 정보를 콤마(,) 로 구분하고 있다.
  IMU 데이터
      IMU ( 자세 정보 ) 정보이다.
      IMU 로 시작하며,
      IMT,IMU_T, …, IMU_GAMDT 등으로 표시
      회전각 3개와 각가속도(G),가속도(A),자기장(M),위치(D),온도 등
      총 16개 데이터와
      마지막 두 개의 체크섬 데이터 있다.
  GPS 데이터
      GPS 의 $GPGGA 또는 $GNGGA 정보를 표시하며,
      GPS_GGA 로 시작하며,
      * 이후는 체크섬을 표시한다.
  ATLM 데이터 : ATLM 으로 시작하며, 8개 데이터와 체크섬이 있다.
  IMAGE 수신 정보 : 이미지 크기와 이미지 파일명을 표시한다.
  메시지 수신 정보 :
      사용자가 송신한 메시지(Qlook포함) 정보를 표시한다.

캔위성 기본 키트 – 캔위성 로그 데이터 구분
   캔위성(내부 uSD) 로그 정보의 각 데이터는 콤마(,) 로 구분하고 있다.

   캔위성 상태 정보
      LIFESIGN,현재시각,수행시각 형태
   GPS 로그
      $GPGGA 또는 $GNGGA, 데이터 저장
   IMU 데이터
      IMU_DATA, 이후 IMU 데이터 저장
   CAMERA 데이터:
      카메라의 운용 상황을 저장하고있다.
      CAMERA_INIT ( 카메라 초기화 할 경우 )
      IMAGE_SIZE,size ( 카메라 이미지 크기 )
      IMAGE_RECEIVED ( 카메라 영상 수신 완료)
   ATLM 로그
      ATLM으로 시작하고 8개 데이터가 있다.
   DTLM 로그
      DTLM4으로 시작하며, 32개 데이터가 있다.

캔위성 기본 키트 – 저장 정보 활용
  상태 창 저장 정보 활용
      상태 정보는 시간 단위로 콤마(,) 로 구분된 CSV 파일로 저장된다.
      CSV 파일은 엑셀 (또는 다른 툴)을 이용하면 편리하게 데이터 추출을 할 수 있다.
  엑셀을 이용한 데이터 활용 ( 예, ATLM 0 번 추출 및 도시)
      Csv 파일을 연다.
      메뉴 > 데이터 > 필터 선택
      B 에서 필터를 ATLM만 선택
      C열 데이터 선택 후 다른 Sheet 에 복사
      메뉴 > 삽입 > 그래프 선택

캔위성 기본 키트 – 저장 정보 활용
  CANSAT_GS.exe 활용 ( GPS 데이터 도시)
      메뉴 > View > GpsDisplay > GpsMap 선택
      Cansat Map 에서 사용자 지정 위치 선택 후 [SET] 버튼
      ( 예: ACenter_LARGE )
      메뉴 > SIMULATION > GPS > Load GPS Log 후 파일 선택
      ( 예: ETC1_SmartCan.csv )
      메뉴 > View > MainScreen > Gps 선택
      메뉴 > View > DisplayRange > 해당 거리 ( ex : 1500m )
