캔위성 기본 키트 – 1. 지상국으로 전송 기능 처리
   지상국과의 무선 통신
      RS232 시리얼 통신 (115200, N,8,1) 사용하여 전송


   데이터 처리부 처리
      초기화 ( 프로세서 ➔ BT ➔ 지상국 )
       • 프로세서의 UART 포트를 115200,N,8,1 로 통신 가능하도록 한다.
       • 2025 버전 이후 부팅 시 CANSAT 보드에서 설정하지 않도록 하였다.
       • BT 모듈은 1번만 초기화하면 된다.
       • BT 모듈과 통신이 안될 경우, 모듈점검보드를 이용하여 따로 설정 가능.
         BT 에 따른 초기화 방법은 다양하며, Firmtech 의 경우 ( MODE2, SLAVE, 115200) 임.

      자료 처리 ( 전송 큐(대기열)를 이용한 데이터 전송 )
       • 보낼 자료는 선입선출(FIFO) 방식의 지상 전송 큐에 데이터를 넣고,
       • 주기적으로 전송 큐(FIFO)에 지상으로 보낼 데이터가 있는지 점검하여,
       • 보낼 데이터가 있으면, UART 포트로 데이터를 전송한다.

캔위성 기본 키트 – 2. IMU 데이터 처리
   IMU (자세센서) 와의 통신
      TTL Level(5V) 시리얼 통신 ( 115200, N, 8,1 ) 으로 IMU 데이터 수신
      IMU의 데이터 출력 형태는 센서 출력에 따라 여러 가지 형태로 선택이 가능하며,
      캔위성 지상국 프로그램에서도 설정이 가능하다.
      출력 형태는 캔위성에 IMU를 장착하기 전에 설정한다. (모듈점검보드 활용 미리 설정)


   데이터 처리                                             IMU
      초기화 ( IMU ➔ 프로세서 경로설정 )
       • 프로세서는 IMU로부터 수신 할 수 있도록 경로(MUX)를 설정하고,            115200

       • 시리얼 통신을 위한 115200, N, 8, 1 로 설정한다.                     MUX

      자료 처리 ( IMU ➔ 프로세서 ➔ 지상국 )
       • IMU 로부터 오는 데이터 형태(포맷)을 확인하여                            CPU
       • 포맷에 맞는 데이터를 수신하면,
       • 데이터를 지상국 IMU 프로토콜에 맞추어                   115200
       • 지상으로 전송한다.                                        BT         uSD
      자료 저장 ( IMU ➔ 프로세서 ➔ uSD )
       • 포맷 확인 후 uSD 카드에 상태 정보를 저장한다.

캔위성 기본 키트 – 5. DTLM 데이터 처리
   DTLM ( 디지털 원격검침(명령) )
      캔위성 기본키트는 32개의 DTLM 를 가지고 있다.
      이들은 지상 명령에 의해 각각 설정이 가능하다.
      특히 0 ~7 번 8개의 DTLM 는 EEPROM 값을 저장하여 , 부팅시 초기화 최종 상태에 따라 동작.
   데이터 처리
      초기화
       • 프로세서는 DTLM을 획득할 수 있도록
       • 프로세서의 포트를 초기화 한다.
      데이터 처리 ( DTLM 획득 ➔ 프로세서 ➔ 지상국 )
       • DTLM 데이터는 8비트 변수 4개( dcmd_0~3 )를 이용한다.
       • DTML 비트 데이터 의미
             0 : GPS 운용 ON/OFF
             1 : IMU 운용 ON/OFF
            ……

       • DTLM 지상국 설정 명령에 의해 데이터 변경 가능
       • DTLM 데이터 지상 전송
             지상국 DTLM 프로토콜에 맞추어 32비트 상태 정보를 지상으로 전송
      자료 저장 : uSD 카드에 상태 정보를 저장한다.
