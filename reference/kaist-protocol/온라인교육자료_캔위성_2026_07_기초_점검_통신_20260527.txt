캔위성 기본 키트 – 기초 성능 점검
   목표 : 캔위성 기본 키트와 지상국 간의 접속 점검
   준비 : 캔위성 기본 키트 + 지상국 통신 장치 + 지상국 프로그램(Cansat_Gs.exe)
   수행 :
      캔위성 : 스위치 ON ( 선택 1 – BT 연결)
      지상국 통신 장치 : 설치 ( COM4 )
      지상국 프로그램 : Cansat_Gs.exe 수행
       • 포트 설정 ( COM4, 115200 )                      PORT DATA 창
       • 접속 설정
   확인 :
      캔위성 : LED 확인
      지상국 통신 장치: 설치 확인
      지상국 프로그램 :
       • 포트 설정시 : 아래 부분 메시지 확인
       • 접속 설정시 : PORT DATA 창 확인

캔위성 기본 키트 – 지상국 프로그램 수행
   지상국 프로그램 수행 ( Cansat_Gs.exe )
      교육자료에서 Cansat_Gs.exe 다운로드
      C:\Cansat 디렉토리에 복사
        • Cansat_Gs.exe 실행
   포트 접속 ( COMPORT 연결 )                         지상국 SW

      메뉴 사용 ( or Toolbar 사용 )
        • 메뉴 > CANSAT_PORT > OPEN
      PORT 설정 창 이용
        • 포트 선택 ( 예, COM4 )
        • 속도 115200 으로 선택                       포트 접속 창

        • [접속] 버튼 클릭 하여 포트 접속
   포트 연결 ( BlueTooth 연결 )
      메뉴 사용 ( or Toolbar 사용 )
        • 메뉴 > CANSAT_PORT > CONNECT
                                                포트 연결 창
      PORT CONNECT Dlg 창 사용
        • ID 입력 ( CANSAT 의 BT 위에 써 있는 ID 입력 )
        • [Connect] 버튼 입력
   데이터 수신 확인
        • 메뉴 > CANSAT_PORT > PORT_DATA
