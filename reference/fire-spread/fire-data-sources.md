# 화재 확산 모델 입력 자료 확보안

기존 바람장의 위치·시각과 발화 위치를 입력받아 계산 영역에 필요한 자료를 프로그램이 조회한다. 아래는 문서 조사에 따른 초기 후보이며 실제 API 호출·국내 적용 검증은 아직 하지 않았다.

| 입력 | 우선 후보 및 자동 접근 | 한계와 확인 사항 |
| --- | --- | --- |
| 지형 | [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/): S3의 전 세계 고도 타일에서 대상 범위를 읽고 경사·방향 계산 | 지역별 원본·유효 해상도·결측·수직 기준과 한국 산지 정확도 확인 필요. 타일 해상도가 원본 정확도는 아니다. |
| 토지피복 | [ESA WorldCover 2021 v200](https://esa-worldcover.org/en/data-access): 공개 S3의 3° 타일 COG에서 대상 범위의 11개 분류값 읽기. 타일 인덱스로 위치별 자동 선택 | 약 10m 분류지만 2021년 자료이며 수종·연료량 미제공. 식생 종류에서 산불 연료 모델로의 변환은 별도 근거·검증 필요. |
| 기상 이력 | [기상청 ASOS 시간자료](https://apihub.kma.go.kr/apiList.do?apiSeq=2)와 [관측소 정보](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=317): 위치 근처 관측소와 시간별 자료 조회 | 인증키 필요. 관측소 거리·고도·결측과 변수별 제공 여부 확인. 기상 시계열의 KST 처리 필요. |
| 사연료 수분 | [Nelson 계열 모델](https://research.fs.usda.gov/download/treesearch/80005.pdf)을 기상 이력으로 구동하는 방안 검토 | 시간별 기온·습도·강수·일사, 초기 상태 등이 필요. 국내 연료 적합성 미검증. 국내 산림연료습도 지도의 수치 API는 미확인. |
| 바람 | 지상국의 GPS 궤적 기반 동·북 이동 추정값 | 관측 위치·고도·시각 및 품질을 유지한다. 화염 높이 풍속 변환과 공간·시간 외삽은 미검증. |

보조 후보 [Open-Meteo 과거 기상 API](https://open-meteo.com/en/docs/historical-weather-api)는 좌표·기간별 기온·습도·강수 등을 제공한다. 재분석 격자값이며 현장 관측값이 아니고 지연·공간 해상도·이용 조건을 확인해야 한다.

## 처리 흐름과 미결 사항

1. 바람장과 발화 위치에서 계산 범위·시각을 정한다. 출처별 범위를 자동 조회하고 응답·시각·버전·결측을 기록한다.
2. 지형과 토지피복을 공통 미터 좌표계 격자로 변환한다. 경사와 경사 방향을 계산하고, 분류값을 근거가 있는 연료 모델 후보로 매핑한다.
3. 기상 관측 이력으로 연료 수분을 추정하거나, 신뢰 가능한 입력이 없으면 결측으로 표시하고 명시적 시나리오를 사용한다. 공기 습도를 연료 수분으로 대입하지 않는다.
4. 바람의 높이·대표성 및 연료 수분과 연료 모델의 불확실성을 보존해 시나리오별 확산 결과를 낸다.

실제 요청 실험, 자료 제공 조건 및 API 키, 데이터 공백 시 동작, 한국 산림의 연료 모델과 관측 검증이 남아 있다. 출처 선택은 잠정이며 실제 화재 대응용 정확도는 확보되지 않았다.

## 연결 시험 (2026-11-02)

시험 좌표 37.5°N, 127°E에서 Terrain Tiles z12 PNG는 HTTP 200, WorldCover N36E126 COG는 HEAD 200과 범위 요청 206을 반환했다. Open-Meteo 과거 기상은 2026-10-20~21 시간별 기온·상대습도·강수·일사 필드를 반환했다. 요청 지점과 응답 격자 위치는 다르다. 이는 연결과 형식 일부만 확인한 것이며 토지피복 픽셀 해석, 국내 고도 정확도, 기상청 API 및 연료 수분 모델은 아직 검증하지 않았다.

## 구현을 위한 자료 계약과 결정

- 입력은 바람 샘플의 위도·경도, UTC 시각, 고도 기준, 동/북 속도와 발화 위치·시각이다. 현재 지상국 샘플 시각은 monotonic 수신 시각이므로 세션 UTC와의 대응을 명시적으로 보존해야 한다. GPS 고도와 지형 고도의 기준 차이를 확인하기 전에는 지상고도로 빼지 않는다.
- 공통 영역은 발화점과 관측 범위를 포함한 경계로 계산하고, 지형·토지피복을 공통 미터 좌표 격자에 정렬한다. 범위·셀 크기는 설정값으로 관리한다. 타일 경계를 넘을 때 모든 교차 타일을 읽으며 결측을 따로 유지한다.
- 지형 Terrarium PNG는 RGB를 `(R*256+G+B/256)-32768`로 복호화한다. Web Mercator 픽셀을 현장 거리로 착각하지 않도록 지역 미터 좌표계에서 경사를 계산한다. 실제 기초 자료 해상도와 수직 기준을 점검한다. [형식](https://github.com/tilezen/joerd/blob/master/docs/formats.md)
- WorldCover는 COG의 수치 분류값을 사용하고 최근접 이웃으로 재표본화한다. 2021년 자료임을 보존한다. 넓은 분류만으로 수종·연료량이 결정되지 않으므로 유일한 Rothermel 연료 모델로 자동 확정하지 않는다. 불확실한 곳은 후보 시나리오 또는 미분류로 표시한다. [자료와 라이선스](https://esa-worldcover.org/en/data-access)
- 기상은 우선 기상청 관측소 메타데이터와 ASOS 시간자료를 인증키로 조회하고, 결측·거리·고도차를 기록한다. 대체 Open-Meteo 과거 자료는 모델 재분석으로 출처 및 응답 격자 위치를 표시한다. 예보 시간의 미래 바람은 과거 재분석으로 대체하지 않는다.
- 기상 이력을 사연료 수분 모델에 넣는 방안은 모델 및 초기값·결측 기준을 확정한 뒤 구현한다. 연료 수분 관측 수치 API는 확인되지 않았다. 값이 없으면 자동으로 정확한 수치처럼 만들지 않고 명시적 가정별 시나리오 또는 계산 불가로 표시한다.
- 조회 결과는 출처·버전·취득 시각·기준 시각·단위·유효 범위와 함께 캐시하고, 실패/오래된 데이터는 표시한다. 각 자료의 사용 조건과 출처 표기를 보존한다.

## 검증 순서

1. 위치·타일 경계·좌표계 및 고도 복호화의 합성 테스트, 실제 타일의 몇 지점 대조.
2. WorldCover 범위 읽기와 코드·결측·경계 테스트. 산림 식생과 연료 매핑의 국내 문헌/현장 검증.
3. 기상청 API의 관측소 선택과 시간대·결측·접근 검증, 재분석 대체 자료의 시차와 해상도 검토.
4. 바람 샘플의 실제 UTC 정렬, 지상고도 및 화염 높이 바람 보정 검증.
5. 독립적으로 검증된 화재 행동 모델의 기준 사례와 비교하고, 실제 화재 확산 관측을 확보해 검증한다.

한국 산림 연료 특성에 대한 연구 사례가 있으나, WorldCover의 넓은 수목 분류는 수종을 제공하지 않아 해당 파라미터를 자동 선택할 수 없다. 임상도의 계산용 API 또는 다른 자동 수종 자료의 확보는 미해결이다. [국내 산불 모델 사례](https://www.mdpi.com/2072-4292/17/16/2824)

## 추가 후보: 국내 임상 정보의 자동 조회

[국토교통부 공간정보 오픈플랫폼 WMS/WFS](https://www.data.go.kr/data/15058805/openapi.do)는 JSON/XML 공간 피처 조회를 지원한다. 외부 서비스 설명에는 임상도 속성(수종·영급 등)의 WMS/WFS 활용 사례가 있으나, 공식 API에서 현재 제공하는 정확한 임상도 레이어명·속성·전국 범위·접근 권한은 확인되지 않았다. 인증키로 capabilities와 실제 feature 응답을 검증하기 전까지 사용 가능하다고 확정하지 않는다. https://pro.aicon.city/Dr_UsageStatisticsMAP/Aicon_%ED%95%AB%EB%A6%BC%EC%9E%A5.pdf

모델의 독립 기준 후보로 [firebehavioR](https://research.fs.usda.gov/treesearch/61523)을 확인했다. Rothermel 기반 계산을 포함하므로 동일 입력에 대한 수치 비교 후보이나, 버전·라이선스·입력 단위 및 구현 차이를 확인하고 비교해야 한다.

## 공통 격자 실험

`log/fire-data-probe/grid_probe.py`는 시험 좌표 주변 100m 간격 5×5 지점에서 Terrarium 고도와 WorldCover 코드를 읽고 고도 유한차분으로 경사 크기를 구한다. 출력은 `log/fire-data-probe/grid_result.json`이다. 지역 좌표 근사와 고정 타일·고정 좌표를 사용한 자료 결합 시험이며 운영 코드, 타일 경계 테스트, 경사 정확도 검증이 아니다. 토지피복 코드 10/40/50은 수목/경작지/시가지를 뜻하며 곧바로 연료 모델이나 방화선으로 단정하지 않는다. https://worldcover2021.esa.int/data/docs/WorldCover_PUM_V2.0.pdf
