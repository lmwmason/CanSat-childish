# 보고서용 그림

2026-10-21 제공 CSV에서 만든 그림 7종이다. 각 그림은 인쇄용 PNG(300 dpi)와 편집 가능한 SVG로 제공한다. 인쇄 크기에서 읽히도록 데이터 선은 충분히 굵게 하고 색을 절제했으며, 큰 그림 내부 제목은 캡션으로 옮겼다. 파일 이름의 숫자 순서대로 보고서에 배치할 수 있다.

그림 1–3과 7은 사출 직후 3초를 제외하고 5초 위치 평활화를 적용한 **추정 결과**다. 그림 4–6은 원본 CSV의 기록값을 **평활화 없이** 표시한다. 그림 4–5의 Child CSV는 10 Hz 기록에 5 Hz GPS 값이 반복된다. 그림 6의 시간축은 모위성 로컬 `ms`를 `events.json`의 시계 정보로 환산했다. 그림 7의 구름은 관측점 주변의 시각화용 보간이며 전체 3D 공간의 실측 풍장은 아니다.

그림 6의 메인 IMU 축은 0–6 g로 표시해 비행 중 변화를 읽기 쉽게 했다. 착지 때의 19.7 g 피크는 오른쪽 위 확대 그래프에 보인다.
