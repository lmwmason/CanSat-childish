# 바람 추정 방법 요약

## 분석 목적과 입력

세 Child의 하강 중 GPS 궤적에서 위치별 **수평 바람의 두 성분**(동쪽, 북쪽)을 추정했다. 입력은 각 Child CSV의 GPS UTC, 위도·경도·고도, GPS 수신 상태와 사출 상태다. 모위성 IMU와 서보 기록은 비행 단계 설명용 그림에 사용했으며 바람 계산에는 넣지 않았다.

## 전처리

1. 보드별 `ms` 시계가 다르므로 세 Child를 GPS UTC로 정렬했다. 기록 주기 10 Hz 사이에 반복된 5 Hz GPS 시각은 한 번만 사용했다.
2. `limit_sw=0`인 사출 후부터 각 Child의 착륙 시각까지, `fix=1`, 위성 수 4개 이상, HDOP 5 이하인 위치를 골랐다. 사출 직후 3초는 초기 운동의 영향을 줄이기 위해 제외했다.
3. GPS 해발고도(MSL)에서 자료의 지면 해발고도 62 m를 빼 지상 기준 고도(AGL)를 얻었다. 위도·경도는 기준점 주변의 지역 동·북 좌표로 변환했다. 예를 들어 동쪽 좌표는 기준 위도 \(\phi_0\)에서 \(x\simeq R\cos\phi_0(\lambda-\lambda_0)\)다.
4. 이웃 위치와 크게 어긋나는 단일 GPS 점프를 검사하고, 시간 중복은 제외했다.

## 속도와 바람 추정

각 시각 \(t_0\) 주변 **5초 창**의 동쪽 위치와 북쪽 위치에 가중 2차 다항식을 각각 적합했다.

\[
x(t_0+\Delta t)\simeq a_x+b_x\Delta t+c_x\Delta t^2,\qquad
y(t_0+\Delta t)\simeq a_y+b_y\Delta t+c_y\Delta t^2.
\]

창 중심의 수평 속도는 \(\mathbf v_h=(b_x,b_y)\)다. 안정적으로 하강하는 Child가 주변 공기의 수평 운동을 충분히 따라간다는 근사에서 \(\hat{\mathbf w}_h\simeq\mathbf v_h\)로 두었다. 풍속은 \(\sqrt{\hat w_E^2+\hat w_N^2}\), 화살표 방향은 **바람이 향하는 방향**이다. 고도별 그림에는 추정값을 **5 m 고도 구간**으로 평균했다.

중력은 주로 수직 운동에 작용한다. 수평 항력 응답 지연을 고려하면 근사식 \(\mathbf w_h\simeq\mathbf v_h+\tau\mathbf a_h\)를 쓸 수 있으나, Child별 유효 항력계수·면적의 검증값이 없어 본 그림의 주 결과에는 적용하지 않았다. 평활화만으로 GPS 위치 잡음의 미분 증폭을 줄인 결과를 사용했다.

## 그림의 범위

- 그림 1–3은 세 Child가 모두 포함된 **7.5–32.5 m AGL** 구간을 중심으로 제시한다. 이 구간의 18개 Child×고도 벡터 평균은 동쪽 **2.00 m/s**, 북쪽 **0.70 m/s**, 합성 크기 **2.12 m/s**이며 향하는 방위는 진북에서 시계 방향 **70.6°**다. 이는 선택한 자료·구간의 평균으로 전체 공간의 참값이나 장비 정확도를 나타내지 않는다.
- 그림 4–6은 저장된 센서 기록을 평활화하지 않고 표시한다. 그림 4의 `spd_mps`는 GPS 수신기가 기록한 수평 속도이며 바람 역산 결과가 아니다.
- 그림 7의 반투명 구름은 18개 고도별 관측점 주변에 가우시안 가중 평균을 적용한 **시각화용 국소 보간**이다. 관측점 \(i\)에서 \(K_i=\exp[-\tfrac12((x-x_i)^2+(y-y_i)^2)/1.7^2-\tfrac12(z-z_i)^2/3.0^2]\)로 두고 \(\hat{\mathbf w}_h=\sum_iK_i\mathbf w_{h,i}/\sum_iK_i\)를 표시했다. 최대 가중치가 0.20 미만인 공간과 공통 관측 고도 밖은 그리지 않았다. 색은 수평 풍속, 투명도는 관측점 근접도를 나타낸다.
- 3D 그림의 세 번째 축은 **위치의 고도**다. 수직 바람을 측정하거나 추정한 3성분 풍장이 아니다. 구름 그림도 관측 궤적 근처에서만 해석해야 하며, 먼 공간으로 확장한 풍장이나 통계적 신뢰구간으로 읽지 않는다.

## 검증 상태

제공 자료의 `README.md`와 생성 스크립트는 데이터 생성 과정을 설명한다. 따라서 그림은 분석·시각화 방법을 보여주는 결과이며 실제 기체의 현장 정확도 평가는 아니다. 실측 자료에 적용할 때는 GPS 시간·고도 기준, Child 질량과 항력 특성, 기준 풍속계와의 동시 측정으로 편향과 오차를 확인해야 한다.
