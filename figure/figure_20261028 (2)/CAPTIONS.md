# 그림 설명

자료: `20261027T231609.215054Z-live`. 아래 그림의 위치는 첫 GPS fix를 원점으로 잡은 지역 동·북 좌표이며 높이는 GPS GGA 원본 고도다.

- **그림 1.** GPS GGA 원본 고도, HDOP, 위성 수와 임시 하강 구간.
- **그림 2.** 전체 GPS 수평 궤적과 선택한 구간.
- **그림 3.** IMU 원본 3축 각도와 선택한 구간; 이 패킷은 가속도계 수치가 아니므로 사출 충격 판정에 쓰지 않았다.
- **그림 4.** 선택 구간의 3D GPS 궤적과 수평 이동 벡터; 화살표의 연직 성분 0은 수직풍 측정값을 뜻하지 않는다.
- **그림 5.** 평활화한 수평 이동 성분의 시간·GPS 고도별 분포.
- **그림 6.** 관측 궤적 주변의 국소 3D 수평 이동 보간; 반투명 구름은 관측점 근처의 보간 표현이며 실제 공간 전체의 풍장 관측이 아니다.
