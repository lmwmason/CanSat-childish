# 보고서용 그림 설명

그림의 `114`, `115`, `116`은 서로 다른 시각에 기록된 Child 시험이다. 사출·착지 시각은 영상으로 확인되지 않았으므로 모든 하강 구간은 GPS 고도에서 자동 선택한 **임시 후보**다. 아래 문장은 그림 아래에 바로 사용할 수 있도록 작성했다.

1. **전체 GPS 수평 궤적.** 세 GoPro 기록의 동·북 위치를 공통 원점으로 표시하고, 각 기록에서 GPS 고도 하락량으로 선택한 하강 후보를 강조했다. 희미한 전체 궤적에는 하강 전후 이동도 포함된다.
2. **GPS 고도와 하강 구간 후보.** 원본 GPS 고도의 시간 변화와 자동 선택된 시작·끝을 표시했다. 기록 115의 고도는 −80.9 m까지 내려가므로 절대 높이나 지상고도로 해석하지 않는다.
3. **GPS 기록 속도.** 각 CSV가 제공한 2D 지상 속도와 3D 속도의 시간 변화를 원본 값으로 표시했다. 급격한 변화는 사건 시각을 검토하는 단서이며 사출의 확정 증거는 아니다.
4. **하강 후보의 3차원 궤적.** 각 후보 구간의 동·북 위치와 원본 GPS 고도를 공간상에 표시했다. 세 경로는 서로 다른 시각의 시험이며 그림의 세로축은 검증된 지상고도가 아니다.
5. **평활화한 수평 이동 성분.** GPS 위치에 11초 국소 2차 다항식을 적합한 뒤 미분해 구한 동쪽·북쪽 이동 속도다. 초기 3초는 사출 과도 구간으로 제외했다. Child가 공기를 따라간다는 근사에서 바람의 대리지표로만 사용한다.
6. **시험별 평균 수평 이동 벡터.** 선택 구간의 동·북 이동 속도를 시험별로 평균했다. 기록 114, 115, 116의 평균 벡터 크기는 각각 0.39, 2.47, 1.96 m/s다. 시험 시각이 달라 세 화살표를 한 순간의 공간 풍장으로 연결할 수 없다.
7. **두 수평 속도 계산 방식의 비교.** GPS 위치의 평활화 미분으로 계산한 크기와 CSV의 GPS 2D 속도를 비교했다. 둘 사이의 차이는 처리 방식과 측정 잡음을 보여주지만 독립 풍속 참값에 대한 오차는 아니다.
8. **GPS 속도 변화율의 사건 단서.** GPS 3D 속도를 평활화한 뒤 시간 미분한 값을 후보 시작 시각 주변에 표시했다. 이 값은 속도 변화율이며 IMU 가속도계 측정값이 아니다. 영상 또는 사출 스위치 기록으로 시작 시각을 검증해야 한다.
9. **GPS `precision` 원본 필드.** CSV에 기록된 `precision` 값을 시간에 따라 나타냈다. 추출기의 필드 변환이 확인되지 않아 절대 위치 오차나 신뢰구간으로 바꾸지 않았다.
10. **관측 위치에서의 3차원 속도 표시.** 하강 후보의 GPS 동·북·고도 위치에 해당 위치의 추정 수평 이동 속도 크기를 색으로 표시했다. 관측점 사이 공간을 채운 3D 풍속장이나 수직풍 측정 결과가 아니다.
11. **시험별 궤적과 고도별 수평 이동.** 위 행은 각 Child의 하강 후보 경로, 아래 행은 5 m GPS 고도 구간에서 평균한 동·북 이동 성분이다. 세 기록은 다른 시각의 시험이다. 기록 115의 원본 GPS 고도는 지상고도가 아니다.
12. **3D 궤적의 수평 이동 화살표.** 관측 경로 위의 위치 추정 수평 속도를 동·북 화살표로 표시했다. 세로축은 원본 GPS 고도이고 화살표에 수직풍 성분을 넣지 않았다.
13. **시험별 국소 수평 단면.** 각 시험의 중앙 GPS 고도 근처 표본에서 추정한 수평 이동 벡터를 화살표로, 표본 주변의 가우시안 보간 속도 크기를 색으로 표시했다. 115번 단면에는 입력 표본이 4개뿐이므로 국소 보간 예시로만 사용한다. 색칠된 영역 밖은 계산하지 않았다.
14. **기록 114의 반투명 3D 구름.** 짧은 하강 후보 경로 주위에서만 수평 이동 속도를 국소 보간했다. 색은 속도 크기, 투명도는 관측 경로와의 근접도를 나타내며 공간 전체의 실측 바람장은 아니다.
15. **기록 115의 반투명 3D 구름.** 독립 하강 후보 경로의 관측 위치 주변에만 국소 보간을 적용했다. 원본 GPS 고도의 음수 구간은 실제 지상 아래 위치로 해석할 수 없다.
16. **기록 116의 반투명 3D 구름.** 독립 하강 후보 경로 주변의 수평 이동 속도 크기를 국소 보간으로 표현했다. 구름의 범위는 보간 표시 범위이며 수직풍이나 공간 전체의 풍속 측정 범위가 아니다.

계산식·입력·구간 선택·한계는 [METHODS.md](METHODS.md)에 정리했다.
